웹사이트명: CULT SOCIETY

제작하게 된 계기

어릴 때부터 일본 빈티지를 좋아해 해외 직구와 세컨핸드 구매를 자주 했습니다. 그런데 국내에서 매물을 찾으려면 후루츠패밀리, 번개장터, 중고나라 등 여러 플랫폼을 동시에 뒤져야 했고, 유행이 붙은 아카이브 피스는 시세가 발매가의 몇 배를 웃도는데도 이를 비교할 수 있는 서비스가 없었습니다. CULT SOCIETY는 그 불편함에서 출발했습니다. 아카이브 패션 피스의 시세 추적 + 중고 거래를 한 곳에서 — 후루츠패밀리의 감성과 KREAM의 호가 시스템을 결합한 플랫폼입니다. "죽지 않는 옷들의 시장. 유행은 끝나도 가치는 남는다."

기능 및 작동 방식

전체 구조
- 아카이브·빈티지 의류의 중고 거래와 실시간 시세 추적을 결합한 플랫폼으로, 프레임워크 없이 HTML·CSS·JavaScript와 Chart.js만으로 구현한 단일 HTML 파일
- 상단 고정 내비게이션 → 시세 티커 → 히어로 → TOP 10 → 지금 거래 중 → MD'S PICK → 브랜드 랭킹 → 거래·입찰 → 마이 클로젯 → 푸터 순으로 배치
- 내비게이션 탭(탐색·시세·거래·아카이브)을 누르면 해당 섹션으로 부드럽게 스크롤되고, 스크롤 위치에 따라 현재 보고 있는 섹션의 탭이 자동으로 활성화됨
- 디자인 아이덴티티: Cinzel(속빈 대문자 로고)·DM Mono(데이터)·Gowun Batang(본문)·Unbounded 글꼴, 애시드 옐로우그린(#d4e84a) 시그니처 색상, 노이즈 그레인 오버레이

상단 영역
- 시세 티커(마키): 인기 아이템의 등락률(↑/↓)이 좌우로 끊김 없이 흐르는 애니메이션. 데이터를 복제해 이어 붙이는 방식으로 무한 순환 구현
- 히어로: 좌측에 슬로건과 통계(아카이브 피스 4,218 / 추적 브랜드 98 / 실시간 시세 업데이트), 우측에 대표 아이템 카드 3개
- 검색창: 브랜드·시즌·아이템명을 입력하면 '지금 거래 중' 그리드를 실시간 필터링. 입력값이 비면 안내, 결과가 있으면 그리드로 스크롤, 없으면 결과 없음 메시지 표시

상품 탐색
- TOP 10 슬라이더: 좌우 화살표로 카드를 넘기는 가로 슬라이더. 화면 폭에 따라 노출 카드 수가 달라지며(데스크톱 5 / 태블릿 3 / 모바일 2), 창 크기를 바꾸면 위치를 재계산해 어긋나지 않음
- 지금 거래 중 그리드: 5열 카드 배열. 각 카드에 브랜드·아이템명·사이즈·현재가·발매가 대비 등락률 표시
- 필터 탭: 전체 / 시세 상승 / 발매가 이하 / 아카이브 / 컬래버 / 일본 빈티지. 조건에 맞는 카드만 남기고 결과 개수를 헤더에 반영하며, 해당 상품이 없으면 안내 문구 표시
- 모든 상품 카드(슬라이더·그리드·히어로 카드)는 클릭하면 상세 모달로 연결. 카드마다 고유 식별자를 지정해 노출 순서가 바뀌어도 정확한 상품 정보가 열림

상품 상세 모달
- 카드 클릭 시 오버레이로 열리며, 배경 클릭 또는 ESC 키로 닫힘
- 대표 이미지·썸네일, 태그·브랜드·아이템명·컨디션, 현재 판매가와 발매가 대비 등락률 표시
- 시세 차트(Chart.js): 거래가 추이를 꺾은선 그래프로 표시. 3개월·6개월·1년 기간 버튼으로 전환, 그래프에 마우스를 올리면 해당 시점 가격이 툴팁으로 표시
- 시세 요약: 발매가 / 52주 최고가 / 52주 최저가
- 거래 이력: 날짜·컨디션·거래가·등락을 표로 표시
- 외부 플랫폼 연동: 같은 아이템이 번개장터·당근·중고나라에 올라온 가상 매물을 현재 컬트 시세와 비교한 가격 차이(%)와 함께 표시. 안전결제 미적용 주의 문구 포함

거래 / 입찰 시스템
- 구매 방식 토글: '즉시 구매'와 '입찰 제시' 패널을 버튼으로 전환
- 즉시 구매: 고정된 구매가와 구매 버튼, 발송·안전결제 안내
- 입찰 제시: 금액 직접 입력 또는 퀵 버튼(280·290·300만)으로 입력
- 입력값 검증: 빈 값, 잘못된 금액, 현재 최고가(2,800,000원) 이하 입찰을 각각 막고 안내 메시지 표시
- 유효한 입찰은 '현재 입찰 현황' 맨 위에 최고가로 추가되고, 기존 최고가 항목은 일반 항목으로 갱신
- 현재 입찰 현황: 입찰자·금액·시간을 최고가 순으로 정렬해 표시

마이 클로젯 (유저 프로필)
- 좌측 프로필 카드: 닉네임·지역, 신뢰 뱃지(인증 셀러·거래 건수), 통계(보유 피스·총 거래·평점·팔로워), 취향 태그
- 우측 탭 전환: 내 옷장(보유 아이템 카드 그리드) / 거래 이력(날짜·아이템·금액·구분·상태 표) / 위시리스트(관심 아이템과 가격 알림 설정)

공통 인터랙션
- 토스트 알림: 화면 하단에 잠깐 떴다 사라지는 안내 메시지. 데모로 구현하지 않은 기능(로그인·판매하기·실제 구매 등)을 누르면 안내 표시
- 반응형: 화면 폭에 따라 슬라이더 노출 개수가 조정됨
- 접근성: ESC 키로 모달 닫기, 마우스 커서는 클릭 가능한 요소에만 포인터로 표시

사용 기술
- HTML·CSS·JavaScript (프레임워크 없이 바닐라로 구현)
- CSS 변수로 색상·테마 일괄 관리, CSS Grid·Flexbox 레이아웃, 키프레임 애니메이션(마키·페이드인·토스트)
- Chart.js로 시세 차트 렌더링
- 상품 데이터를 JavaScript 객체에 저장하고, 카드 클릭 시 해당 데이터를 모달에 동적으로 채워 넣는 구조

본 프로젝트는 학습용 데모로, 결제·로그인·실제 거래 등 서버 연동이 필요한 기능은 안내 메시지로 대체되어 있습니다.
